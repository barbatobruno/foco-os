# Foco·OS — app (PWA)

App de controle de OS da Foco Engenharia, empacotado como PWA para instalar no celular.

## Arquivos
- index.html — o app
- manifest.webmanifest, sw.js — tornam instalável e offline
- icon-192.png, icon-512.png — ícones

## Publicar (GitHub Pages)
1. Crie um repositório público e suba todos estes arquivos.
2. Settings > Pages > Deploy from branch: main / (root).
3. Abra a URL gerada no celular e "Adicionar à tela inicial".

> Sincronização entre celular e PC será adicionada na próxima etapa (Firebase).
